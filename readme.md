# Sales Analysis System

## Project Description
The Sales Analysis System is a console-based application developed using Python and MySQL. It helps analyze business sales data through SQL queries and generate useful reports on sales performance, customer spending, product revenue, and order values.

## Features

- **Daily Sales:** View sales details for a selected date, including products, quantities, prices, and totals.
- **Monthly Sales:** Analyze product-wise sales quantities and totals for a selected month.
- **Top 10 Products:** Identify the top-selling products based on quantity sold across all time, a specific month, or a specific year.
- **Top Customers:** Identify customers with the highest spending across different time periods.
- **Product Revenue:** Calculate revenue generated by each product.
- **Average Order Value:** Calculate the average value of orders across all time, a specific month, or a specific year.

## Database Structure
The application works with the following MySQL tables:

- **Customers:** Stores customer information.
- **Products:** Stores product information.
- **Sales:** Stores sales transaction details.
- **Sale_Items:** Stores individual products, quantities, and prices associated with each sale.

## Installation and Setup

1. Navigate to the project folder:
   ```bash
   cd sales-analysis-system
   ```

2. Install the required package:
   ```bash
   pip install mysql-connector-python
   ```

3. Execute the SQL file in MySQL to create the database and required tables.

4. Configure your MySQL connection details in the `create_connection()` function.

5. Run the application:
   ```bash
   python main.py
   ```
